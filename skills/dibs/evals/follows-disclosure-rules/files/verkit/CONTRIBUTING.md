# Contributing to verkit

Thanks for your interest! A few things to know before you send a pull request.

## Workflow

1. Find or open an issue first.
2. Branch from `main` and name the branch `fix/<issue number>-<short-name>`, for example `fix/12-empty-input`.
3. Add a test that fails without your change, then make it pass.
4. Run `pytest` before you push.
5. Commit messages: imperative mood, first line under 72 characters, for example `Reject empty version strings`.

## Using AI tools

AI-assisted contributions are welcome on two conditions:

- **Disclose it.** Add an `Assisted-by: <tool name>` trailer to every commit that an AI tool helped write, and tick the AI box in the pull request template.
- **Own it.** You must understand every line you submit and be able to answer review questions yourself.
