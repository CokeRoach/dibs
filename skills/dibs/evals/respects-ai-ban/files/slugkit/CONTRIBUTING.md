# Contributing to slugkit

Thanks for helping! slugkit is looked after by two volunteers in their spare time, so please read this before you start.

## Before you start

- For anything bigger than a typo, comment on the issue first so we can agree on the approach.
- One pull request per issue.

## AI-generated contributions

We do not accept contributions made with AI coding assistants or large language models (ChatGPT, Copilot, Claude, Cursor and the like). This covers code, tests, documentation, issues and pull request descriptions. We review every line ourselves, and we need to trust that the person who sent it wrote and understood it. Pull requests that look AI-generated will be closed without review.

## Running the tests

    pip install -e . pytest
    pytest

## Style

Black, 100 columns.
